# Internet Map User Manual

## InternetMap-Geographic 3D

[InternetMap-Geographic 3D](geographic-3d/README.md) displays an emulated network on an interactive globe. Rotate and zoom the globe to explore the geographic distribution of nodes and connections between regions. The view supports live and uploaded topologies, node search, filtering, and traffic replay.

![InternetMap-Geographic 3D network view](../../InternetMap-Geographic/docs/assets/current-map-3d.png)

## InternetMap-Geographic 2D

[InternetMap-Geographic 2D](geographic-2d/README.md) displays an emulated network on a flat world map. It helps you compare regions, locate hosts and routers, and follow connections across the network. You can explore a running experiment or upload a saved topology, filter nodes, and inspect packet activity.

![InternetMap-Geographic 2D network view](../../InternetMap-Geographic/docs/assets/current-map-2d.png)

## InternetMap-Toplogy

[InternetMap-Toplogy](topology/README.md) presents an emulated network as a connectivity diagram. It helps you understand relationships between hosts, routers, Internet exchanges, and transit networks. You can explore different levels of detail, search for nodes, inspect live packet activity, or upload a saved topology for offline viewing.

![InternetMap-Toplogy network diagram](../../InternetMap-Toplogy/docs/assets/map.png)
